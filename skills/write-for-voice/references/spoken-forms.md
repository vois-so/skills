## Versions, code and technical text

| Written | Spoken |
|---|---|
| v2.6.2 | "version two point six point two" |
| iOS 18 | "i O S eighteen" |
| Node.js 18+ | "Node J S eighteen or a newer version" |
| `npm install` | "run npm install", or "install the package" |
| C++ | "C plus plus" |
| C# | "C sharp" |
| .NET | "dot net" |
| SHA-256 | "sha two fifty-six" |

Do not read code to a listener. Say what the code does. If the listener must type a command, show it on the screen and say only its name.

## Symbols

| Written | Spoken |
|---|---|
| & | "and" |
| + | "plus", or "and" |
| = | "equals", or "is" |
| / | "and", "or" or "per". Select the word that agrees with the meaning. |
| -> or => | "then", or "goes to" |
| @ | "at" |
| # | "number", or "hashtag". Select the word that agrees with the meaning. |
| * | Remove it. If it means "times", write "times". |
| ... | Keep it only where the speaker stops to think. |
| ( ) | Make a new sentence, or use commas. |
| ; | Use a full stop. |
| — (a long dash) | Use a full stop or a comma. |

## Acronyms

Make a decision for each acronym. Write the full name at the first use. Then use the short name.

| Type | Write it as | Examples |
|---|---|---|
| The speaker says the letters | Letters with spaces | "A P I", "U R L", "S Q L", "C L I", "A W S" |
| The speaker says a word | The word | "NASA", "JSON", "SaaS", "GIF" |
| The listener does not know it | The full name only | "recovery point objective", not "RPO" |

If you are not sure, make a test file and listen. If the acronym is incorrect in many scripts, add a pronunciation entry in Vois Studio.

## Lists

Written:

```text
Benefits:
- Lower cost
- Better quality
- Faster delivery
```

Spoken:

```text
[Narrator]: This gives you three things. First, the cost goes down. Second, the quality goes up. Third, you get it faster.
```

## Tables

Change each row that the listener must have into one sentence. Remove the other rows.

Written:

| Plan | Price |
|---|---|
| Basic | $5/mo |
| Team | $20/mo |

Spoken:

```text
[Narrator]: The basic plan costs five dollars a month. The team plan costs twenty.
```
